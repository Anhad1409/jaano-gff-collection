# The Jaano Collection

Six premium design renditions of **Jaano's GFF 2026 brochure card (No. 08)** — front and back for each — plus **the Exploration Wall**: twenty further front-card concepts, all on a single self-contained page with version labels and the design idea behind every direction.

Jaano is Blostem's video KYC + video PD verification platform. *Jaano* is Hindi for "to know" — the campaign line is **"Anyone can verify. Jaano knows."**

## The Exploration Wall (C01–C20)

Twenty concept directions — abstract, editorial, cinematic, cryptographic — several with an intrigue mechanic: a dossier that declassifies on hover (C02), a spotlight you steer with your cursor (C05), a polygraph that never stops writing (C03). Highlights: Specimen, Guilloché, Chiaroscuro, Helvetic, Bauhaus, Iris, Mercury, Blueprint, Checksum, Contact Sheet, Sonar.

## Viewing

Open `index.html` in any browser — the page is fully self-contained (all fonts embedded as data URIs, no external requests, no build step). Or visit the hosted GitHub Pages URL for this repo.

## Print

All cards sit at the brochure's 62:82 ratio. Animations are screen-only and freeze cleanly in print. Swap the placeholder QR for the live one before exporting at 300 dpi.

## Fonts

Bodoni Moda, Cormorant Garamond, Cinzel, Archivo, Rozha One — all under the SIL Open Font License, embedded inline.
